1. Tertiary buttons for All / New

Uses the unmodified .btn-tertiary metrics: 16px, weight 700, 2px / 4px padding, muted text, no fill, text brightens on hover. That is the same as “New Folder” and “New Branch” today, and it is smaller than the 18px Chat / Git tabs. The active Chat tab keeps its raised fill and blue underline, so tabs still read as tabs and All / New read as quiet actions.

2. Suggestions as inline diffs

Instead of showing the whole original and the whole replacement, one chip shows a word-level diff: red struck-through = removed, green = added. Colors reuse .diff-ins / .diff-del from the editor. Hover previews the replacement in the draft (as today); click applies. Very short suggestions (one or two words) could keep the current two-chip layout.

3. Smaller send button in the composer corner

The button sits inside the input, bottom-right. It is 24px square (the existing, currently unused --size-control token) and inset 8px (--space-4, equal to the textarea's own vertical padding) from the right and bottom edges. On a one-line, 40px input that leaves 8px above and below, so it is centered. The icons are Font Awesome Free 7.3.1 solid (CC BY 4.0). The input uses the full row width. Variant C keeps A's colors (--color-accent fill, white arrow, gray when disabled) but copies the editor toolbar button's shape: 1px transparent border, 0 var(--space-3) padding, 16px icon, --radius-2. It is 2rem (32px) square instead of 36px so it fits a 40px input with a 4px (--space-2) inset. Type in the boxes to see the states.
